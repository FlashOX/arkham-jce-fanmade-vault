# Archives d'Arkham

Catalogue communautaire de contenu **fan-made** pour *Arkham Horror : le Jeu de Cartes*
(campagnes, scénarios indépendants, enquêteurs).

## Pourquoi ce projet

Le contenu fan-made circule aujourd'hui via des liens Google Drive personnels : si le
contributeur s'en va ou ferme son compte, tout disparaît. Ce projet remplace ça par une
solution pérenne et sans dépendance à une personne :
- **Fichiers** hébergés sur [archive.org](https://archive.org) — infrastructure à but non
  lucratif, URL stables, gratuit.
- **Catalogue** = site statique servi par GitHub Pages depuis une **organisation** GitHub
  (plusieurs admins), pas un compte perso.

## État

🚧 **Proof of concept.** Le catalogue tourne avec des fiches d'exemple ; l'architecture
d'hébergement est décrite dans [`plan_hebergement_ahlcg.md`](plan_hebergement_ahlcg.md).
